# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] — October 2026

### Added
- Config generator (Engine.ini, multi-threading, shader cache, async loading)
- FPS presets (low-end, mid-range, high-end, competitive)
- Controller mapping (keyboard remapping, gamepad layout, Steam Input)
- Backup and restore system
- Portable build (no installation required)
- Native C++ build, 1.8 MB, no runtime dependencies

### Security
- No telemetry, no ads, no bundled software
- Only modifies local config files
- Full source code available for audit

### Known Issues
- Game Pass version not yet supported
- DLSS/FSR configurator planned for v1.2.0
