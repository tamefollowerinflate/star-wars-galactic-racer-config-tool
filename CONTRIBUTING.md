# Contributing

Thanks for your interest in improving Star Wars Galactic Racer Config Tool!

## How to contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/my-feature`)
3. Commit your changes (`git commit -m 'Add some feature'`)
4. Push to the branch (`git push origin feature/my-feature`)
5. Open a Pull Request

## Guidelines

- Keep the tool config-only — no game memory modification
- No external dependencies (native C++ only)
- Test on Windows 10 and Windows 11
- Update CHANGELOG.md with your changes
- Follow the existing code style

## Reporting bugs

Open an issue with:

- Windows version
- Star Wars Galactic Racer patch version
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable

## Suggesting features

Open an issue with:

- Clear description of the feature
- Why it would be useful
- Any implementation ideas

## Pull Request process

1. Ensure your code compiles without warnings
2. Update README.md if needed
3. Update CHANGELOG.md
4. Wait for review — we aim to respond within 48 hours
