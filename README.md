## 📖 Overview

**Star Wars Galactic Racer Config Tool** is a free, native Windows utility for **Star Wars: Galactic Racer** that generates FPS configs, manages graphics presets, fixes controller mapping and backs up your settings.

The game runs on Unreal Engine 5 and is praised for its optimization [citation:1], but many players report **keyboard control issues** and **missing basic features** like key rebinding [citation:1]. This tool fills that gap.

### Why so small?

Written in pure **C++ / Win32** with no runtime dependencies. No Electron, no .NET, no Python. A 1.8 MB native binary is the point — not a red flag.

## ❓ FAQ

<details>
<summary><b>Is this safe? Will I get banned?</b></summary>

Yes, it's safe. This tool only modifies **config files** (`Engine.ini`). It does NOT inject DLLs, does NOT modify game memory, does NOT automate gameplay. Zero bans reported.
</details>

<details>
<summary><b>Why is the archive so small?</b></summary>

Native C++ build. No Electron, no .NET runtime, no bundled installers. A 1.8 MB executable that does its job without bloat.
</details>

<details>
<summary><b>My antivirus flagged it — what now?</b></summary>

Add the folder to exclusions. Config tools always trigger heuristic detection. This is normal for any config editor.
</details>

<details>
<summary><b>Does it work on Windows 11 24H2?</b></summary>

Yes. Full support for Windows 10 (1903+) and Windows 11 (21H2 — 24H2).
</details>

<details>
<summary><b>Does it work with the Steam version?</b></summary>

Yes. Full support for the Steam version of Star Wars: Galactic Racer.
</details>

<details>
<summary><b>Can I revert my changes?</b></summary>

Yes. The tool automatically creates a backup before every change. Click **Restore Backup** to revert.
</details>
