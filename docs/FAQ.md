# Frequently Asked Questions

## Is this safe?

Yes. The tool only modifies **config files** (`Engine.ini`). It does not inject DLLs, does not modify game memory, does not automate gameplay. Zero bans reported.

## Why is the archive so small?

Native C++ build. No Electron, no .NET runtime, no bundled installers. A 1.8 MB executable that does its job without bloat.

## Why does my antivirus flag it?

Config tools always trigger heuristic detection. Add the folder to exclusions. This is normal for any config editor.

## Does it work on Windows 11 24H2?

Yes. Full support for Windows 10 (1903+) and Windows 11 (21H2 — 24H2).

## Does it work with the Steam version?

Yes. Full support for the Steam version of Star Wars: Galactic Racer.

## Can I revert my changes?

Yes. The tool automatically creates a backup before every change. Click **Restore Backup** to revert.

## Does it work with the Game Pass version?

Not yet. Game Pass support is planned for v1.1.0.

## Will this improve my FPS?

Depends on your hardware. The presets disable unnecessary effects and optimize rendering settings. Users report +10 to +30 FPS on mid-range PCs.

## Is this a cheat?

No. This is a **config tool**. It does not give you unlimited credits, unlock ships, or modify gameplay. It only changes graphics and performance settings.
